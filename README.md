# fantasy-rts-prototype

简化的奇幻中世纪 RTS 原型（基于 Phaser 3）。

功能：
- 六个阵营（人类、精灵、兽人、死灵、恶魔、矮人）
- 阵营选择 -> 单张地图 -> 单位生成（玩家/AI）
- 鼠标框选 + 右键移动/攻击命令
- 简易 AI 产兵并进攻

运行方法：
1. 下载或克隆仓库。
2. 在本地直接打开 `index.html`（无需服务器）或使用静态服务器（推荐 VS Code Live Server）。
3. 桌面浏览器中操作：左键单击/拖框选择单位；右键下达移动或攻击命令。

后续计划：替换像素精灵、增加单位技能与阵营差异化、加入建筑/资源系统并部署 GitHub Pages.
